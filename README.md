# Quopro downloads

Quopro is a Windows quoting application published by Moses Ford, New Zealand. This repository contains customer instructions and release notes. The application is proprietary; no permission to redistribute, modify or reverse engineer it is granted by this repository.

## Download

Open this repository's **Releases** page and choose the approved version supplied by Moses Ford. Download its `Quopro.exe` asset. Do not use GitHub's **Source code** ZIP or TAR downloads as the application installer.

No customer release is available yet. Version 1.3.5 is a verified development candidate. It is unsigned and is not approved for commercial deployment.

## Activate your PC

1. Open `Quopro.exe`. Quote functions stay locked until activation.
2. Copy the PC request code and send it to Moses Ford through your agreed purchase or support channel.
3. Paste the activation code Moses provides and select **Activate Quopro**.

Each activation applies to its original PC request. The app checks the licence locally. Updates and repeat downloads keep activation on the same hardware and Windows profile while its local activation files remain intact.

Contact Moses before changing the motherboard, moving to another Windows profile, reinstalling Windows or replacing a licensed PC. A replacement request may need a new activation code. Preserve your local customer and pricing data before updating or changing PCs.

## Updates and support

Automatic updating is not available yet. Use only a release approved by Moses Ford and follow its release instructions. Your purchase agreement determines licence allocation, support and replacement-PC terms. A public download alone does not grant a licence.

Use the support channel supplied with your purchase. Do not post activation codes, request codes, quotes, customer information or pricing in public GitHub issues. No public support address has been assigned yet.
