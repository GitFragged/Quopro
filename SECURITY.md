# Security and private information

Report a suspected security issue to Moses Ford through the private contact channel supplied with your purchase. Do not publish details that expose a licence, customer information or an exploitable defect in public issues. A dedicated public security contact has not been assigned yet.

Development candidates are not approved customer releases. Code protection, trusted Windows signing and authenticated automatic updates remain release tasks. An unsigned executable's checksum can confirm identical bytes, but it does not establish a trusted publisher identity.

Hardware activation deters ordinary sharing. It cannot make software impossible to inspect, modify or bypass. Current licences are checked offline and cannot be remotely revoked.
